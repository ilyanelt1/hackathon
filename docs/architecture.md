# Архитектура MVP

## Компоненты

- Backend API: FastAPI, HTTP API и бизнес-логика.
- Database: PostgreSQL 17, основное хранилище стажёров, опросов, ответов и аналитики.
- Frontend: React + TypeScript + Vite (будет добавлен отдельной задачей).
- ETL: загрузка, нормализация и проверка исходных данных.
- AI analysis: анализ обратной связи и объяснимые аналитические сигналы.

## Первый вертикальный срез

На начальном этапе реализован только GET /health. Он позволяет Docker и CI проверить доступность backend. Подключение БД, доменная модель, API-эндпоинты и UI будут добавляться последовательно.

## Локальная инфраструктура

Docker Compose поднимает PostgreSQL и backend. Backend стартует после успешного healthcheck базы. Секреты и локальные настройки задаются через .env; .env.example содержит безопасные шаблонные значения.

## Принципы

1. Валидация входных данных на границах системы.
2. Миграции схемы БД вместо ручного изменения структуры.
3. Отсутствие персональных данных в логах.
4. AI-результаты объяснимы и проверяются человеком.
5. Проверки качества выполняются до принятия изменений в main.
